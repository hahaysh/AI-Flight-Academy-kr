# 나에게 맞는 비행 고도는?

::: tip 실제로 계속 사용할 도구를 선택하세요
가장 어려운 고도를 선택한다고 상을 받는 것은 아닙니다. Scout나 Code가 더 고급스럽게 들린다는 이유만으로 선택할 필요도 없습니다. 목표는 세션이 끝난 뒤에도 일상에서 사용할 도구에 익숙해지는 것입니다. 다시 사용할 것 같은 도구를 골라 그 환경에서 만들어 보세요. Cowork, Scout, Code 어느 것을 선택해도 작동하는 결과물을 만들 수 있습니다.
:::

## 잘 모르겠다면

- **에이전트를 만들어 본 적이 없거나 설정 없이 시작하고 싶나요?** 🟢 **Cowork**를 선택하세요.
- **조금 설정하더라도 더 많은 기능을 사용하고 싶나요?** 🔵 **Scout**를 선택하세요. Microsoft 365와 GitHub 계정이 필요합니다.
- **VS Code가 익숙하거나 바이브 코딩에 도전하고 싶나요?** 🟣 **Code**를 선택하세요.
